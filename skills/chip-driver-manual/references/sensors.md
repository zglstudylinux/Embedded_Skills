# 传感器

用于 IMU、温度传感器、压力传感器、光传感器、电流/功率监测器、编码器和电量计等测量器件。

## 通用提取项

- 被测量量、单位、分辨率、输出数据格式、端序和缩放公式。
- 接口地址、寄存器表、命令集和自动递增行为。
- Device ID 或 WHO_AM_I 寄存器。
- 电源模式、启动时间、复位序列和配置默认值。
- 输出数据率、带宽、oversampling、averaging 和 filter 设置。
- 满量程范围、增益、偏移、校准、补偿和 factory trim 用法。
- Data-ready、threshold、motion、alarm、FIFO 和 fault 中断。
- 状态位、错误标志、overflow/overrun 行为和清除方法。
- 转换时间、样本延迟和同步行为。

## 驱动风险

- 在确认有符号性、位对齐和端序前，不要应用缩放。
- 不要假设寄存器自动递增存在。
- 遵守启动和首个样本丢弃要求。
- 保留校准系数和补偿公式。
- 处理陈旧数据、FIFO overflow 和中断锁存。
