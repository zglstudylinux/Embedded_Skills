# 文档质量

在信任 datasheet 或手册中的提取取值前，先评估提取质量。

## 质量检查

- 统计页数和提取文本总长度。
- 检查页标记是否保留。
- 搜索替换字符、mojibake 或破损符号，例如 `???`、`U+FFFD`、常见 UTF-8/Windows-1252 解码伪影或缺失单位。
- 检查电气、时序、寄存器、命令和排序章节附近的表格。
- 核验 min/typ/max、read/write、reset 和 units 等列是否在提取中保留下来。
- 检查图中是否包含文本提取无法捕获的关键事务图。
- 判断扫描页是否需要 OCR。

## 风险标签

在输出中使用这些标签：

- `text_ok`：正文可读。
- `mojibake`：符号或非 ASCII 文本乱码。
- `table_loss`：表格列不可靠。
- `figure_required`：波形、时序图或封装图承载关键信息。
- `needs_ocr`：页面看起来是扫描件，或几乎未提取出文本。
- `needs_manual_review`：关键取值存在，但提取置信度低。

将 `mojibake` 视为警告，而不是自动失败。有些 datasheet 包含大量 Unicode 单位、符号、连字或排版字符，会提高非 ASCII 计数，但技术文本仍然可用。

## 表格处理

- 除非能看到列标题，否则不要从破损行推断 min/typ/max 值。
- 引用时序和电气值时带上单位。
- 将特定电压范围的取值分开记录。
- 对含糊行标记 `needs_table_review`。
- 优先将表格取值与功能摘要、正文、示例或 SDK 常量交叉核验。
