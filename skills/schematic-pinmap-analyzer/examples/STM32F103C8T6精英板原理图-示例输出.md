# STM32F103C8T6 精英板 原理图功能引脚文件

依据：`STM32F103C8T6精英板原理图.pdf`（共 3 页：Page1 Power / Page2 Driver&Interface_1 / Page3 Driver&Interface_2，其第 3 页含 Pin Mapping 权威映射块）。本文档中 IO 表"U3-xx"为原理图 U3（STM32F103C8T6-Card 核心板符号）的卡引脚号，并附 J1/J2 扩展座对应脚号。

## 1、电源架构分析：输入电源路径

| 电源轨 | 来源器件 | 输出 | 去向 | 备注 |
|---|---|---|---|---|
| VIN | P1（2P 端子，1=VIN/2=GND）、DC1（DC 电源座，中心正 PIN4=VIN，PIN2/PIN3=GND） | VIN | SW1 | 直流输入接口，两种输入口并联 |
| VCC | SW1（SS-1230W-G2 拨动开关，PIN2=VIN、PIN3=VCC、PIN1=NC） | VCC | U1 VIN、TB6612 U4 VCC/STBY | 总开关；VCC 同时接 TB6612 逻辑电源 |
| +5V | U1 TPS5430DDAR（Buck：VIN=VCC，PH→L1 22uH→+5V，D1 B340A 续流，C1 10nF BOOT，C7/C8 4.7uF 输入，C2 220uF 输出，R1 10K/R2 3.24K 反馈 VSENSE，ENA 悬空 NC） | +5V | U2 IN、H1 排针、Type-C VBUS 轨、舵机座 H4/H5/H11/H12、UART 座 H8/H9/H15/H16、循迹座 CN3、电机编码器座 CN1/CN2、CAN 收发器 U8、+5V 电源灯 LED1 | ENA 悬空（芯片默认状态决定是否使能，原理图未画使能网络）；Type-C VBUS 与 Buck 输出共轨，无隔离器件 |
| 3V3 | U2 SCJA1117B-3.3-A（LDO：IN=+5V，C3 10uF/C4 100nF 输入，C5 100nF/C6 10uF 输出） | 3V3 | U3 核心板（VCC3V3、VBAT）、H2 排针、W25Q16、CH340N、ESP8266、OLED、MPU 座 U10、Grove 座 H6/H7/H13/H14、HC-SR04 座 H10、用户 LED3/LED4 阳极、3V3 电源灯 LED2 | MCU 及多数外设供电域 |
| GND | 公共地 | GND | 全板 | — |

- 输入路径：`DC1/P1 → VIN → SW1 → VCC → U1(TPS5430DDAR) → +5V → U2(SCJA1117B-3.3-A) → 3V3 → U3 核心板及 3V3 外设`；Type-C VBUS（USB1 PIN2/PIN11，经 CC1/CC2 对地 R8/R6 5.1K）可直接向 +5V 轨供电。
- 电源指示灯：+5V→LED1（红）→R3 10K→GND；3V3→LED2（绿）→R4 4.7K→GND，上电常亮。
- H1（PZ254V-12-8P）：1/3/5/7=+5V、2/4/6/8=GND；H2（PZ254V-12-8P）：1/3/5/7=3V3、2/4/6/8=GND，对外引出电源。
- 原理图可见范围内无反接保护、保险丝/PTC、TVS；TB6612 电机电源网络 TB_VM 仅连 U4 VM1/VM2/VM3（PIN24/14/13），图中未见任何电源输入。

## 4、驱动逻辑分析

- **电源输入与总开关（P1/DC1/SW1）**：VIN 输入 → SS-1230W-G2 拨动开关 → VCC。无软件参与，仅需软件知晓断电状态无保持。
- **DC-DC 降压 U1（TPS5430DDAR）**：VCC→+5V，固定硬件反馈（R1 10K/R2 3.24K），ENA 悬空；纯硬件，无需软件配置。
- **LDO U2（SCJA1117B-3.3-A）**：+5V→3V3 给 MCU 与 3V3 外设；纯硬件。
- **电源指示灯（LED1 红 + R3 10K、LED2 绿 + R4 4.7K）**：接 +5V/3V3 与 GND 之间，上电常亮，与 MCU 无关。
- **用户 LED（LED3 红、LED4 绿）**：3V3→LED→4.7K→PC13/PC14，低电平点亮。注意 PC14 同时驱动继电器：PC14=低 → LED4 亮且继电器断开；PC14=高 → LED4 灭且继电器吸合。建议初始化 PC13/PC14 为推挽输出且默认低（LED 亮、继电器保持断开）。
- **按键（SW2=KEY3/PB5、SW3=KEY2/PB6、SW4=KEY1/PB7）**：按键一端接 GND，另一端接 MCU 脚，无外部上拉。低电平有效，软件必须配置内部上拉；检测按下=低电平，可用 10~20ms 消抖或下降沿中断。
- **继电器驱动（U9 SRD-5VDC-SL-C + Q2 NPN + D2 1N4148）**：RELAY（PC14）经 R14 10R 驱动 Q2 集电极负载线圈，R15 10K 基极下拉保证复位/上电默认断开，D2 反向续流。高电平有效。触点：COM（U9-5）接 +5V，NO（U9-2）接 P3-1，P3-2 接 GND——吸合时 P3-1 输出 +5V；R13 10K + LED5 串联于触点与 GND 间作吸合指示。软件：PC14 推挽输出，默认低，置高吸合。
- **蜂鸣器驱动（U7 + Q1 PNP + R5/R7 100R）**：Q1 发射极接 3V3、集电极接 U7 正极，U7 负极经 R7 100R 接 GND；PC15 低电平导通 PNP 鸣叫，低电平有效，默认（浮空/高）不响。U7 为有极性蜂鸣器符号，有源/无源需确认（见第 5 部分）。
- **USB 转 TTL（U5 CH340N + USB1 Type-C）**：Type-C CC1/CC2 经 R8/R6 5.1K 下拉，VBUS 直接进 +5V 轨，USB_DP/USB_DN 接 CH340N UD+/UD-；CH340N 供电 3V3，V3 脚接 3V3，RTS# 悬空。CH340N TXD（网络 USB_TX）、RXD（网络 USB_RX）经 H3 跳线选择接到 USART1（PA10/PA9）或 USART2（PA3/PA2）：左列跳帽 6-4=USART2 收、4-2=USART1 收；右列跳帽 5-3=USART2 发、3-1=USART1 发。软件按所选串口初始化即可，波特率由 PC 端/业务决定。
- **SPI Flash（U6 W25Q16JVSSIQ，2MB）**：SPI2 引脚 PB12(/CS)/PB13(SCK)/PB14(MISO)/PB15(MOSI)；IO2（WP#）、IO3（HOLD#）均上拉 3V3，VCC=3V3，C15 100nF 去耦。/CS 低有效，建议软件片选（GPIO 推挽，空闲拉高），SPI 模式 0/3；PB12~PB15 与 Grove/循迹传感器直连，访问 Flash 时相关传感器须不冲突。
- **CAN 收发器（U8 TJA1050T/CM,118）**：VCC=+5V（C16 100nF），S 脚接地（高速模式），VREF 悬空；TXD←PA12（CAN_TX）、RXD→PA11（CAN_RX）；CANH/CANL 间板载 R9 120Ω 终端电阻并引至 P2（1=CANL、2=CANH）。软件配 bxCAN（PA11/PA12 复用）；注意 PA11/PA12 同时直连 TB6612 BIN1/BIN2，CAN 与电机 B 方向控制互斥。
- **电机驱动（U4 TB6612FNG）**：逻辑电源 VCC=VCC 网络、STBY 硬连 VCC（上电常使能，无法软件休眠）；电机电源 VM1/VM2/VM3 共接 TB_VM 网络，原理图中 TB_VM 未接任何电源（需外部补接，见第 5 部分）。控制：PWMA=PA0、AIN1=PA4、AIN2=PA5（电机 A）；PWMB=PA1、BIN1=PA11、BIN2=PA12（电机 B）；输出 AO1/AO2→CN1-6/CN1-1，BO1/BO2→CN2-1/CN2-6。典型控制：IN1=1/IN2=0 正转、IN1=0/IN2=1 反转、IN1=IN2=0 滑行、PWM 占空比调速；PWM 频率需按业务确认。CN1/CN2 的 2/5 脚给编码器供 +5V/GND。
- **编码器接口（CN1/CN2，HX-XH2.54-6PWZ）**：CN1：1=AO2、2=+5V、3=L_ENCA（PA6）、4=L_ENCB（PA7）、5=GND、6=AO1；CN2：1=BO1、2=+5V、3=R_ENCA（PA8）、4=R_ENCB（PA9）、5=GND、6=BO2。软件用 TIM3（PA6/PA7）编码器模式读左轮，TIM1（PA8/PA9）读右轮；注意 PA9 与 USART1_TX 共用。
- **OLED 接口（OLED1，4P：GND/3V3/OLED_SCL/OLED_SDA）**：I2C 于 PB8/PB9（F103 I2C1 重映射脚），地址与分辨率按模块确认。
- **MPU6050 接口（U10，8P）**：5=MPU_SDA（PB11）、6=MPU_SCL（PB10）、7=GND、8=3V3，1~4 脚悬空未接（AD0/INT/XDA/XCL 未引出）。I2C2 总线；SDA/SCL 无板上上拉电阻，需开内部上拉或依赖模块自带。
- **ESP8266 接口（U11 ESP8266-01S）**：RXD←ESP_RX（PA2/USART2_TX）、TXD→ESP_TX（PA3/USART2_RX）、EN 直连 3V3 常使能、VCC=3V3、RST/IO0/IO2 悬空。软件用 USART2 与 ESP8266 AT 指令交互。
- **蓝牙接口（H16，4P：1=BLE_RX、2=BLE_TX、3=GND、4=+5V）**：BLE_RX=PB10、BLE_TX=PB11（USART3），与 MPU6050 的 I2C2 复用，二者互斥。
- **UART 扩展座（H8/H9/H15）**：均为 1=GND、2=TX、3=RX、4=+5V；H8=USART1（UART1_TX/UART1_RX）、H9=USART2（UART2_TX/UART2_RX）、H15=USART3（UART3_TX/UART3_RX），供外接串口模块。
- **超声波接口（H10，4P：1=3V3、2=TRIG/PB4、3=ECHO/PB3、4=GND）**：PB4 推挽输出触发脉冲，PB3 输入捕获测回响脉宽；使用 PB3 前需释放 JTAG。
- **循迹接口（CN3，HX-XH2.54-7PZZ：1=R2/PB12、2=R1/PB13、3=M/PB14、4=L1/PB15、5=L2/PA15、6=+5V、7=GND）**：5 路红外对管输出直入 MCU，均为数字输入；有效电平（黑线/白线对应电平）按模块确认。与 Flash 的 SPI2 四线共用 PB12~PB15，互斥使用。
- **Grove 传感器座（H6/H7/H13/H14）**：H6（LIGHT_DO→PB12）、H7（SMOKE_DO→PB13）、H13（RED_DO→PB14）均为 1=NC、2=信号、3=GND、4=3V3；H14（DHT11_DO→PB15）为 1=NC、2=3V3、3=信号、4=GND。数字/单总线输入，与 Flash 及循迹共用 PB12~PB15，互斥使用。
- **舵机接口（H4/H5/H11/H12，均 1=信号、2=+5V、3=GND）**：SERVO1=PA0（与 PWMA 共用）、SERVO2=PA1（与 PWMB 共用）、SERVO3=PB0（TIM3_CH3）、SERVO4=PB1（TIM3_CH4）。
