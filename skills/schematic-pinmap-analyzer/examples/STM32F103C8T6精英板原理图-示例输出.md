## 1、电源架构分析：输入电源路径

| 电源轨 | 来源器件 | 输出 | 去向 | 备注 |
|---|---|---|---|---|
| VIN | P1（2P 端子）、DC1（DC005 插座） | VIN | SW1 | 外部直流输入，输入电压范围图中未标注（UNKNOWN）；P1 与 DC1 并联为同一路 VIN |

输入路径：`DC1/P1 外部直流输入 → VIN → SW1 → VCC → U1(TPS5430DDAR) → +5V → U2(SCJA1117B-3.3-A) → 3V3；并联供电路径：USB1 Type-C VBUS → +5V`

电源指示灯（非 MCU 控制）：+5V → LED1 → R3 10K → GND；3V3 → LED2 → R4 4.7K → GND，上电常亮。H1（+5V/GND）、H2（3V3/GND）为电源扩展排针。

## 4、驱动逻辑分析

- **电源输入与开关（SW1 SS-1230W-G2）**：P1/DC1 双输入 → SW1 → VCC；原理：外部直流经拨动开关控制整机供电；输入电压范围 UNKNOWN；软件无需参与，上电时序由硬件决定。
- **DC-DC 降压（U1 TPS5430DDAR）**：VCC → +5V；BOOT-PH 间接 C1 10nF 自举，PH 经 L1 22uH 储能、D1 B340A 续流，R1 10K/R2 3.24K 分压反馈至 VSENSE，ENA 引脚未连接（芯片内部使能）；纯硬件电路，软件无需配置。
- **LDO（U2 SCJA1117B-3.3-A）**：+5V → 3V3，输入/输出退耦电容齐全；纯硬件，软件无需配置。
- **Type-C 供电与 USB 转 TTL（USB1 + U5 CH340N）**：Type-C VBUS 直接并入 +5V 轨（CC1/CC2 各经 R8/R6 5.1K 下拉识别），USB_DP/USB_DN 接 CH340N 的 UD+/UD-；CH340N 供电 3V3（V3 脚同接 3V3，RTS# 悬空），其 TXD→USB_TX 网络、RXD←USB_RX 网络；USB_TX/USB_RX 与 MCU PA2/PA3（USART2）并接，并延伸至 H3 排针（H3：1=PA2、2=USB_TX、3=PA9、4=PA10、5=USB_RX、6=PA3）；软件以 USART2 收发，注意同网络多对象（CH340/ESP8266/H9/H3）分时使用，避免双驱动的电平竞争。
- **SPI Flash（U6 W25Q16JVSSIQ）**：/CS=FLA_CS（PB12）、CLK=FLA_SCK（PB13）、DO/IO1=FLA_MISO（PB14）、DI/IO0=FLA_MOSI（PB15），VCC=3V3，IO2/IO3 均上拉至 3V3，C15 100nF 退耦；软件按 SPI2（PB12-15 为 SPI2 默认引脚）配置：CPOL=0/CPHA=0 模式 3 地址类命令时序、片选低有效，与其他 PB12-15 挂接设备（寻迹、Grove DO、DHT11）分时复用。
- **CAN 收发器（U8 TJA1050T/CM,118）**：TXD←CAN_TX（PA12）、RXD→CAN_RX（PA11），VCC=+5V（C16 100nF 退耦），S 引脚接地（正常高速模式），VREF 悬空，CANH/CANL 间 R9 120R 终端电阻并引出至 P2 端子（2=CANH、1=CANL）；软件将 PA11/PA12 配置为 bxCAN 复用功能；注意 U8 为 +5V 供电，其 RXD 输出高电平由 +5V 侧决定（高于 3.3 V IO 电平）；与 TB6612 BIN1/BIN2 复用同一引脚，二选一。
- **直流电机驱动（U4 TB6612FNG）**：PWMA=PA0、PWMB=PA1、AIN1=PA4、AIN2=PA5、BIN1=PA11、BIN2=PA12，STBY 硬件上拉至 3V3（常使能，软件不可断电待机），逻辑 VCC=3V3（C11/C12 退耦），VM（TB_VM 网络）= VCC 原始输入电压轨（C9/C10 退耦）；AO1/AO2、BO1/BO2 分别经 CN1（1=AO2、2=+5V、3=L_ENCA、4=L_ENCB、5=GND、6=AO1）、CN2（1=BO1、2=+5V、3=R_ENCA、4=R_ENCB、5=GND、6=BO2）接左右电机与编码器；软件：方向脚推挽输出，PWM 由 TIM2_CH1/CH2 输出，速度=PWMA/PWMB 占空比，方向由 xIN1/xIN2 电平组合决定（00 停止、01/10 正反转、11 刹车）。
- **编码器输入**：左轮 L_ENCA=PA6、L_ENCB=PA7（TIM3 编码器模式），右轮 R_ENCA=PA8、R_ENCB=PA9（TIM1 编码器模式）；编码器供电 +5V（CN1/CN2 第 2 脚）；软件配置定时器编码器计数模式，双相计数 4 倍频；注意 R_ENCB 与 UART1_TX 复用 PA9，二选一。
- **舵机接口（H4/H5/H11/H12）**：SERVO1=PA0、SERVO2=PA1、SERVO3=PB0、SERVO4=PB1，均为 1=信号、2=+5V、3=GND；软件用 TIM2_CH1/CH2（PA0/PA1）与 TIM3_CH3/CH4（PB0/PB1）输出 50 Hz PWM，0.5–2.5 ms 脉宽控制角度；PA0/PA1 同时驱动 TB6612 PWM，周期需兼容。
- **OLED 显示（OLED1）**：GND/VCC(3V3)/SCL=OLED_SCL(PB8)/SDA=OLED_SDA(PB9)；软件可用 I2C1 重映射（PB8/PB9）或软件 I2C 驱动，图中未见总线，上拉依赖 OLED 模块板载电阻（UNKNOWN）。
- **六轴传感器（U10 MPU6050 模块）**：SDA=MPU_SDA（PB11）、SCL=MPU_SCL（PB10），供电 3V3（第 8 脚），GND（第 7 脚），其余 4 脚（含 AD0/INT 类引脚）原理图中挂绿色未连接标志；软件按 I2C2（PB10/PB11）时序读写；器件地址由 AD0 电平决定，图中未连接（UNKNOWN）。
- **WiFi 模块（U11 ESP8266-01S）**：RXD←ESP_RX（PA2）、TXD→ESP_TX（PA3），VCC=3V3 且 EN 与 VCC 并接 3V3（常使能），IO0/IO2/RST 悬空；软件以 USART2 与其通信；注意与 CH340、H9、H3 共网分时使用。
- **蓝牙接口（H16 排针）**：1=BLE_RX（PB10）、2=BLE_TX（PB11）、3=GND、4=+5V；软件以 USART3 与外接 BLE 模块通信；与 MPU6050（I2C2）、H15（USART3）三路共享 PB10/PB11，同一时刻只用一路。
- **蜂鸣器驱动（Q1 + U7）**：PC15（BUZZER 网络）→ R5 100R → Q1 PNP 基极，Q1 发射极接 3V3、集电极接 U7 蜂鸣器正极，U7 负极经 R7 100R 接 GND；原理：PNP 高侧开关，PC15 输出低电平→Q1 导通→蜂鸣器发声，低有效；软件推挽输出，默认高电平（静音）。
- **状态 LED（LED3/LED4）**：3V3 → LED3 → R11 4.7K → LED2 网络（PC13）；3V3 → LED4 → R12 4.7K → LED1 网络（PC14）；均为低电平点亮；软件推挽输出，PC13 控制红灯、PC14 控制绿灯。
- **按键（SW2/SW3/SW4）**：KEY3=PB5、KEY2=PB6、KEY1=PB7，按键另一端接 GND，外部无上拉电阻；软件使能内部上拉，按下读到低电平，轮询或 EXTI 下降沿中断+消抖。
- **继电器驱动（U9 SRD-5VDC-SL-C + Q2）**：PC14（RELAY 网络）→ R14 10R → Q2 NPN 基极，R15 10K 基极下拉，集电极接线圈低侧，线圈经 R10 10R 接 +5V，D2 1N4148 反向续流；高电平→Q2 导通→继电器吸合（高有效）；触点侧引出 P3 端子（1=+5V、2=开关触点），LED5+R13 10K 作吸合指示；软件推挽输出高电平吸合；注意 PC14 同时接 LED4 指示灯（低电平点亮，与吸合状态相反）。
- **超声波测距（H10 HC-SR04 接口）**：1=3V3、2=TRIG（PB4）、3=ECHO（PB3）、4=GND，模块 3V3 供电；软件：PB4 推挽输出 ≥10 µs 触发脉冲，PB3 输入捕获高电平脉宽换算距离；PB3/PB4 为 JTAG 引脚，需先释放 JTAG。
- **5 路红外寻迹（CN3 HX-XH2.54-7PZZ）**：1=R2（PB12）、2=R1（PB13）、3=M（PB14）、4=L1（PB15）、5=L2（PA15）、6=+5V、7=GND，传感器 +5V 供电；软件将 PB12-PB15、PA15 配置为上拉数字输入（需释放 PA15 的 JTAG 功能），读黑线电平；与 SPI Flash、Grove DO 共用 PB12-PB15，分时复用。
- **Grove 传感器接口（H6/H7/H13/H14）**：H6：2=LIGHT_DO（PB12）、3=GND、4=3V3；H7：2=SMOKE_DO（PB13）、3=GND、4=3V3；H13：2=RED_DO（PB14）、3=GND、4=3V3；H14：2=3V3、3=DHT11_DO（PB15）、4=GND（1 脚均未连接）；软件：LIGHT/SMOKE/RED 三个 DO 配置上拉数字输入读开关量；DHT11 为单总线时序，PB15 开漏/推挽切换双向驱动。
- **串口扩展排针（H8/H9/H15）**：H8：1=GND、2=UART1_TX（PA9）、3=UART1_RX（PA10）、4=+5V；H9：1=GND、2=UART2_TX（PA2）、3=UART2_RX（PA3）、4=+5V；H15：1=GND、2=UART3_TX（PB10）、3=UART3_RX（PB11）、4=+5V；软件按对应 USART 外设初始化即可，注意 PA9 与右轮编码器、PB10/PB11 与 MPU6050 的复用冲突。
- **板级扩展（J1/J2 XH2.54-20P）**：J1 引出 3V3/GND/+5V 与 PB3-PB9、PA8-PA12、PA15、PB12-PB15；J2 引出 3V3/GND/RST 与 PC13-PC15、PA0-PA7、PB0/PB1、PB10/PB11；引脚名与核心卡引脚一一对应，供外接使用。
